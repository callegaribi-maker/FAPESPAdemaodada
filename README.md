# Observatório de Quedas · Pará

Painel interativo do projeto **"De mãos dadas para não deixar cair: o perfil do equilíbrio estático e o risco de quedas das mulheres paraenses"** (LEMOH/UFPA · FAPESPA, Termo de Outorga 105/2024).

- 1.093 participantes, 22 municípios, 4 Macrorregiões de Saúde do Pará
- Abas: Panorama, Municípios, Ciclo de vida, Fatores de risco, Equilíbrio postural (estabilometria OA/OF), Cruzamentos livres e Método
- Dados desidentificados (sem nome, telefone ou endereço)

## Publicar no GitHub Pages
1. Crie um repositório e envie o `index.html` para a raiz.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O link fica em `https://<seu-usuario>.github.io/<nome-do-repositorio>/`.
